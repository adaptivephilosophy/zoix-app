# Zoix (app iOS) / Zoix iOS App

**Français :** Application iOS gratuite de l'Adaptive Philosophy Foundation (Olympia, WA). Elle affiche la page d'accueil de [zoix.ai](https://zoix.ai) pour les nouvelles, une liste native des derniers articles du commons Notion, un mot français du jour, et un bouton « Faire un don » qui ouvre la page de don dans Safari.

**English:** A free iOS app from the Adaptive Philosophy Foundation (Olympia, WA). It shows the [zoix.ai](https://zoix.ai) homepage for updates, a native list of the latest articles from the Notion commons, a French word of the day, and a Donate button that opens the giving page in Safari.

## Plan / Plan

- Accueil : zoix.ai dans une vue web / Home: zoix.ai in a web view
- Nouvelles : liste native des articles, recherche et filtres par étiquette / Updates: native article list with search and tag filters
- Mot du jour : mot français du jour / Word of the day: French word of the day
- Faire un don : ouvre la page de don dans Safari (règle 3.2.2 de l'App Store) / Donate: opens the giving page in Safari (App Store guideline 3.2.2)
- Plus tard : notifications pour les nouveaux articles / Later: notifications for new articles

## Construction / Build

**Français :** Compilation sur les runners macOS de GitHub Actions (gratuits pour les dépôts publics), puis envoi vers TestFlight.

**English:** Built on GitHub Actions macOS runners (free for public repositories), then uploaded to TestFlight.
